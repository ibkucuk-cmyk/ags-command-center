# AGS Command Center

> **Private** — Internal B2B operations hub for Advanced Granite Solutions.

## Quick Start

Open `dashboard/ags_dashboard.html` in your browser — no server needed.

## Rebuild Dashboard

After editing any `.md` file, regenerate the dashboard:

```powershell
powershell -ExecutionPolicy Bypass -File "dashboard\build.ps1"
```
